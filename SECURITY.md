# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately via [GitHub private vulnerability reporting](https://github.com/khal-os/usage-component/security/advisories/new), or email <matheus.martino@namastex.ai>.

You should receive an acknowledgement within 72 hours. Please include enough detail to reproduce (endpoint, payload, version/commit) and, if relevant, the impact you believe it has.

## Scope

This repository contains the observability component (module, connector, core, ui) of Khal OS. Deployment/infrastructure issues (Terraform under `deploy/`) are in scope too.
